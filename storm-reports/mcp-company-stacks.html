What Every Architecture Has in Common

  1. Four layers, always the same shape. Client → identity/gateway → thin stateless server → existing backend. No company deviates; they differ only in which layer they own and monetize.
  2. The hard layer is never hand-built. Transport and OAuth come from an official SDK (GitHub, Google, AWS servers) or a managed platform (Cloudflare, Azure APIM, AgentCore). Independent research found 100% of audited DIY OAuth deployments were flawed — this is why.
  3. Three languages, one output. Go (GitHub, Google — static binary, small attack surface), TypeScript (the entire Cloudflare ecosystem), Python (AWS — fastest to build). All produce a thin, stateless, Streamable-HTTP server.
  4. The model vendors set the rules, not the servers. Anthropic and OpenAI host almost nothing; their near-identical client requirements (Streamable HTTP + OAuth 2.1 + review) are the production standard. Build to that bar once and you work with Claude, ChatGPT, and Copilot alike.
  5. For our sovereignty build: keep the four-layer shape, but replace the managed pieces with self-hosted equivalents — agentgateway or IBM mcp-context-forge for the gateway, Keycloak for identity, Go or Python thin servers on in-Kingdom infrastructure. Avoid Cloudflare's edge platform specifically — it is global by design.
